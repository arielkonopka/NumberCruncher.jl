Walk-forward run

Hides each of the last N values in turn, reconstructs the phase space from everything before it (PECUZAL) and estimates the hidden value from the k nearest neighbours. Neighbours within the Theiler window of the last state are excluded, and the seed makes a run reproducible. Several k values are scored from the same reconstruction at almost no extra cost.

Stop lets the reconstructions already in progress finish. Each point costs one PECUZAL run (from under a second to a minute, depending on window and max delay).
